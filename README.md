📌 Project Overview

The Climate Trend Analyzer is an end-to-end data science project that analyzes historical climate data such as temperature, rainfall, humidity, and CO₂ levels to identify trends, detect anomalies, and predict future patterns.

This project simulates real-world climate analytics used by environmental agencies, researchers, and policy makers.

 🎯 Problem Statement

Climate change is a critical global issue. Understanding long-term environmental patterns helps in:

* Predicting climate risks
* Supporting sustainable planning
* Making data-driven environmental decisions


💡 Features

* 📊 Data Cleaning & Preprocessing
* 📈 Trend Analysis (Temperature & Rainfall)
* 🚨 Anomaly Detection (Unusual Climate Events)
* 🔮 Forecasting (Future Predictions using ML)
* 🌐 Interactive Dashboard (Streamlit)


🛠️ Tech Stack

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
* Streamlit

⚙️ Installation

```bash
git clone https://github.com/yourusername/Climate-Trend-Analyzer.git
cd Climate-Trend-Analyzer
pip install -r requirements.txt
```

▶️ How to Run

### Run main project:

```bash

```
Run dashboard:

```bash
streamlit run app/app.py
```
